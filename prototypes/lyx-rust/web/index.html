沿用 LyX 的操作方式

\ 或 Ctrl+Space
开始输入命令或 Typst 公式，如 frac、alpha 或 frac(a, b)。草稿以蓝色直体显示，只有 Enter 才转换为公式。
Enter / Tab
命令输入中，Enter 确认命令或解析完整表达式；Tab 和点击候选只填入补全，不退出输入。普通公式中的 Enter 不换行。
空格
命令输入中，空格和括号按原样保留，不触发确认。普通公式中空格退出当前结构，文本槽中则输入空格。
← → / ↑ ↓
命令输入中，左右键移动草稿光标，上下键选择候选，边界处也不退出。普通公式中进入/退出嵌套结构，分式上下切换，矩阵按列移动。
Tab / Shift+Tab
在当前对象的槽位中循环；单槽对象则退出。分母之后回到分子。
^ / _
进入或创建左侧对象的上/下标。选中文字会进入标注内容。
Esc
取消命令输入或选区；否则退出一层结构。
Backspace
大对象先选中再删除；在槽开头按退格，会去掉外层结构并保留当前槽内容。
普通输入
字符逐个插入，不合并运算符，也不触发 SVG。单字符配置可直接改变显示字形，源码不变；多字符键仅在命令确认或导入时匹配。保留 /、^、_ 等结构快捷键，草稿和字符串仍显示原文。
字符模式
输入 " 开始，另一个 " 或 Enter 结束。字符串带浅色边框，空字符串也可见。空格、运算符与反斜杠作为文本保留。命令草稿中 Enter 先闭合字符串，再次 Enter 才提交命令。
/ 与换行对齐
普通公式中 / 将选区或左侧对象放入分子，并进入分母。命令中 a/b 按 Typst 语法解析；草稿中的单个反斜杠换行，& 划分对齐槽，列按右、左交替对齐，&& 保留空槽。Tab 切换槽位，上下键按列移动。
SVG 公式
结构树中每个未知子表达式对应一个 SVG，其外层分式等结构仍可编辑。浅色边框标明范围，空 SVG 也可见。方向键跨过，Backspace/Delete 整块删除；支持撤销。编译失败时保留源码，从左侧按 → 或右侧按 ← 可进入失败块源码，也可点击“编辑”；修改后回车重试，Esc 恢复原文。
复制 / 粘贴
复制选区得到 Typst 源码；粘贴进入命令模式，保留剪贴板原文，Enter 后才解析。Esc 取消并恢复被替换的选区。已有草稿时粘贴到草稿光标处。

普通公式中的第一个反斜杠唤起命令输入；草稿中的反斜杠按 Typst 语法处理，单个反斜杠表示换行。使用 \alpha 输入符号，直接键入 alpha 则表示五个数学字母。
