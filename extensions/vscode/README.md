# Visual Typst for VS Code

把 `.typ` 作为自定义文本编辑器打开：完整源码编辑、一个共享的结构公式编辑会话，以及基于当前未保存文档的整页预览。

安装匹配平台的 VSIX 后，右键 `.typ` → **打开方式 / Reopen Editor With → Visual Typst**。也可执行 **Visual Typst: 打开混合编辑器**。无需启动 HTTP 服务。

推荐同时安装 **Tinymist Typst**（`myriad-dreamin.tinymist`），扩展会桥接它提供的诊断、补全、悬停、跳转和格式化。结构公式及整页预览使用随附的 Rust/WASM 核心和原生 Typst 引擎。

## 预览

默认右侧显示整页实时预览；也可点击 **预览** 切换。源码编辑后自动编译，编译错误时保留上一次成功页面。预览使用文档自身的字号和页面设置，不套用结构编辑器的显示字号。已打开且未保存的项目内依赖文件也参与预览。支持缩放、适应宽度和手动刷新。

预览需要工作区或已保存文件；本地编译、字体发现和包下载在工作区所在扩展宿主执行。当前 VSIX 随附对应平台的原生程序，不适用于 vscode.dev 纯浏览器宿主。

## 公式与快捷键

每个编辑按钮都注册为独立的 **Visual Typst:** 命令。点击 **快捷键** 打开 VS Code 键盘快捷方式配置，搜索对应操作，双击即可改键，也可使用 `keybindings.json` 设置组合键、条件和多段快捷键。

| 默认快捷键（macOS 用 Cmd 替代 Ctrl） | 操作 |
| --- | --- |
| Ctrl+Alt+I | 插入行内公式 |
| Ctrl+Alt+B | 插入行间公式 |
| Ctrl+Alt+E | 编辑光标处公式 |
| Ctrl+Alt+Enter | 完成公式 |
| Ctrl+Alt+P | 显示／隐藏整页预览 |
| Ctrl+Alt+F | 格式化 |
| Ctrl+S / Ctrl+Z / Ctrl+Y | 保存／撤销／重做 |

加行、加列、刷新公式、包安装及各个预览操作也可自行绑定。公式外的左右键从紧邻边界进入公式；上下键按相邻视觉行和横向位置进入。Shift+方向键仍保留选区语义；纯源码显示时保持代码导航。

公式内使用 `\` 输入命令、Enter 确认、Tab 切换槽位、`/` 创建分式、`^` / `_` 创建上下标。在最外层按 Esc 返回正文。行内公式字号跟随 VS Code `editor.fontSize`。

公式框按内容自然尺寸增长，不把内容压缩到固定框中。宽度以当前编辑列为上限，高度以半个窗口或 360px 中较小者为上限，超出时在公式框内显示滚动条。输入和导航会滚动到当前槽位，手动滚动仍可浏览其他部分。结构上下标保留正常的首层字号差异，深层嵌套以 12px（不超过基准字号）为下限，避免逐层缩到不可读。

文档保存、脏标记和文件状态由 VS Code TextDocument 管理。撤销与重做由扩展宿主维护本文档的历史并用 `WorkspaceEdit` 回放，因为 VS Code 自带的 `undo` 命令只作用于聚焦的代码编辑器，Webview 聚焦时无法到达这个 TextDocument。并发修改发生冲突时保留当前输入，显示两个可选处理动作，不会静默覆盖输入。

包面板可以查询官方版本、安装并插入 import。使用标准 Typst 包缓存，未安装的传递依赖可能需要先由 Tinymist 下载。首版提供整页 SVG 预览，尚无预览到源码的双向定位及 PDF 导出按钮。

## 开发

仓库根目录执行 `build-vscode.cmd` 生成 VSIX。扩展不依赖 `prototypes/`，打包后不依赖仓库路径。
