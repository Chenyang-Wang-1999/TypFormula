# 字符显示映射

`symbols.json` 是一个 JSON 字典：键是 Typst 源码片段，值是希望显示的 Unicode 字符（也可使用字符串）。例如：

```json
{
  "times": "x",
  ">=": "≥",
  "\\/": "/",
  "\\\\": "\\"
}
```

`times` 在编辑器中可以显示成 `x`，复制和导出仍然是 `times`，不会替换成显示字符。默认配置使用乘号 `×`，可以自行修改。希腊字母默认使用 Unicode 数学斜体字形；显示层不会再改写字典的值。

JSON 本身需要转义反斜杠：上面的 `"\\/"` 匹配 Typst 源码 `\/`，`"\\\\"` 匹配 Typst 源码中的两个反斜杠 `\\`。它们分别表示斜杠字符和反斜杠字符。数学语法中的 `a/b` 仍然生成分式，单个 `\` 仍然换行，`&` 仍然分割对齐槽。

解析器通过字典将符号、简写、转义和未知表达式节点映射为显示字符。新增单字符显示语法糖：普通公式中的 `Char` 在渲染时查询该字符的完整键，例如直接输入 `-` 显示为 `−`、`*` 显示为 `∗`，内部对象仍为原来的字符，复制和导出仍是原字符。单字符指一个 Unicode 标量，不限制为 ASCII；显示值也不会再次经过数学斜体转换。

多字符键仍只在解析阶段匹配：直接输入 `<=` 不合并成 `≤`，直接输入 `times` 仍是五个字符。命令草稿和字符串模式按原文显示；`/`、`^`、`_`、反斜杠、双引号、空格等现有快捷行为优先，字典不覆盖它们。

字典不参与补全或输入模式判断。已识别的分式、根式等结构及字符串内容优先按各自语法处理；不会在整个源码里做文本查找替换。未知函数调用可按完整原始片段匹配，内部空格也属于键。未命中字典的未知节点继续使用 Typst SVG；`dif` 默认没有映射。

修改后在仓库根目录运行 `build-desktop.cmd`（或 `cargo build`）。配置在编译期嵌入核心，不需要运行时读取文件。构建时会检查字典格式以及空键、空值；格式有误会直接报错。
